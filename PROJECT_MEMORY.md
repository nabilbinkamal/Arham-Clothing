# 🧠 Project Memory: Arham Clothing

## Overview
- **Project Name:** Arham Clothing (E-Commerce Platform)
- **Repo:** `https://github.com/iamnabil12/Arham-Clothing`
- **Design Style:** Minimalist, premium, modern clothing brand aesthetics.
- **Payment:** Cash On Delivery (COD).

---

## Tech Stack
| Layer | Technology |
|-------|-----------|
| Frontend | React 19 + Vite |
| Styling | Vanilla CSS (`index.css`) |
| Backend | Node.js + Express |
| Database | MySQL |
| Auth | Firebase Google Sign-In + JWT |
| Icons | Lucide React |
| Animations | Framer Motion |

## Deployment Protocol
- Live Oracle VM Server deployment via SSH/SCP.
